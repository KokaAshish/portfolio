# /design

This folder contains design artifacts for the portfolio.

## What to put here

Before submitting, add at minimum:

- [ ] `home-desktop.png` — homepage wireframe or mockup, desktop view
- [ ] `home-mobile.png` — homepage, mobile view
- [ ] `project-desktop.png` — project case study page, desktop view
- [ ] `project-mobile.png` — project case study, mobile view
- [ ] `contact-desktop.png` — contact page, desktop view
- [ ] `contact-mobile.png` — contact page, mobile view
- [ ] `dark-light-comparison.png` — both themes side by side

If you have a Figma or Penpot file, export it here too.

## Tools to use

Recommended: **Excalidraw** (free, in-browser, exports PNG). Sign in with GitHub, create wireframes, export as PNG into this folder.

Alternative: take annotated screenshots of the running site if you do your design work in-browser.

The evaluators are looking for evidence that you *designed before you coded*. Export early wireframes even if the final design differs — the diff is actually interesting.
